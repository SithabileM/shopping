# Django E-commerce Website for Women

A women-focused e-commerce web application built with django, designed to offer a smooth and personalized shopping experience. The website is built to empower women through a convenient, secure, and user friendly interface.

## Problem Scenario 

Many existing e-commerce platforms often provide a one-size-fits-all experience that lacks personalization and focus. Women in particular, face challenges such as:
Overcrowded product listing with no relevance to their preferences.
Limited focus on women-led brands or needs, such as maternity, beauty, or wellness products.
Cultured user experience that does not prioritize simplicity or intuitive design.

This application was built to address these gaps by offering a platform tailored to women - with carefully categorized products, a minimalist design, and features that make shopping efficient and enjoyable.

##Features
Product listing
Add to cart and quantity updates
Secure user authentication
Admin dashboard for managing inventory and orders

## Technologies Used

Backend: Django
Frontend: HTML, CSS, Javascript
Database: SQLite(can be upgraded to PostgreSQL)
Authentication: Django's built-in user system

## Installation

### Clone the repository
git clone htpps://github.com/SithabileM/shopping.git
cd shopping
### Create a virtual environment
python -m venve venv
venv\Scripts\activate
### Install dependencies
pip install -r requirements.txt
### Apply migrations
python manage.py migrate
### Create a superuser
python manage.py createsuperuser
### Run the development server
python manage.py runserver
